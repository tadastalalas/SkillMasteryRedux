[color=#ffff00][size=4]What's new in v1.5.7.1 (since v1.5.7.0)[/size][/color]
[color=#ffd966]Attribute bonuses from Better Attributes, reworked: every attribute point gives bonuses, sorted under the attribute that fits them.[/color]
[color=#93c47d]On by default for every hero, AI lords included, with lower values than Better Attributes.[/color]
[color=#ffd966]The attribute tooltip in the character screen lists each attribute's bonuses.[/color]
[color=#93c47d]Better Attributes is switched off automatically when both mods are loaded, so bonuses do not add up.[/color]

[color=#ffff00][size=4]Features[/size][/color]
[color=#ffd966]Skipped perks can be learned after you have learned the last perk of a skill.[/color]
[color=#93c47d]The higher you level the skill, the more skipped perks you can unlock, one tier at a time.[/color]
[color=#ffd966]Your clan's heroes can learn them too and pick them up by themselves.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#93c47d]AI lords master skills too.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#ffd966]Your own mastery perks can be picked up for you automatically.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#93c47d]Every hero keeps learning a skill at a minimum learning rate, even past its learning limit.[/color]
[color=#ffd966]The character screen skill bar shows the level from which a skill only learns at the minimum rate.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#93c47d]The character screen hero list marks heroes with unspent attribute or focus points and perks to choose.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#ffd966]On-screen messages when a mastery perk is unlocked and when a skill is fully mastered.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#93c47d]Every attribute point gives bonuses: 26 bonuses under Vigor, Control, Endurance, Cunning, Social and Intelligence, in the character screen order.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#ffd966]Each bonus can be switched off, made stronger or weaker, and limited to you, your clan or all heroes.[/color]
[color=#93c47d]The character screen attribute tooltip lists the attribute's bonuses for the selected hero.[/color]
[color=#ffd966]Better Attributes is switched off automatically when both mods are loaded.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#93c47d]Works with or without Mod Configuration Menu.[/color]
[color=#ffd966]Translations for 12 languages.[/color]

[color=#ffff00][size=4]Compatibility[/size][/color]
Can be added/removed [color=#93c47d]anytime[/color]. Mastery perks a hero already earned stay with the hero.
Does [color=#93c47d]not add data[/color] to save game files.
Uses Harmony patches on the character screen and on the vanilla learning rate; the learning rate is only raised after vanilla calculated it, so other mods that change learning keep working.
The attribute bonuses are added after the base game calculated each value (combat, hit points, party size, wages, morale, renown, income and more), so other mods that change these keep working.
Vanilla perk choice is untouched - you still pick one perk per tier first.
Attribute and focus points, the character level cap and the XP tables are vanilla.
[color=#93c47d]Better Attributes:[/color] switched off automatically while [color=#ffd966]Overwrite Better Attributes Mod[/color] is on; with it off, the bonuses of both mods add up.
[color=#93c47d]Realistic Battle Mod:[/color] keep [color=#ffd966]Crush Through Power[/color] and [color=#ffd966]Slice Through Chance[/color] off (the default); RBM has its own rules for both.
[color=#e06666]Not compatible with:[/color] Skill Mastery, Skill Mastery Fix, Show Skill Limit, Minimum Learning Rate. This mod already includes them, so disable them.

[color=#ffff00][size=4]Installation[/size][/color]
Updating? [color=#e06666]Delete the old mod folder first[/color], never overwrite it.
Advisable to use [color=#ffd966]7zip[/color] to extract archive.
Put it in [color=#ffd966]Mount & Blade II Bannerlord[/color]\[color=#f1c232]Modules[/color] folder.
Enable the mod in the launcher. [url=https://www.nexusmods.com/mountandblade2bannerlord/mods/2006]Harmony[/url], [url=https://www.nexusmods.com/mountandblade2bannerlord/mods/2102]UIExtenderEx[/url] (and [url=https://www.nexusmods.com/mountandblade2bannerlord/mods/612]Mod Configuration Menu[/url], if you use it) must be above it.

[color=#ffff00][size=4]Found a problem?[/size][/color]
Generate a crash report link using [url=https://www.nexusmods.com/mountandblade2bannerlord/mods/2018]ButterLib[/url] mod. How to do that the mini guide is here: [url=http://bannerlordmodding.lt/guides/how_to_report_a_crash/]How To Report A Crash[/url]
Turn on [color=#ffd966]Logging for debugging[/color] in [color=#ffd966]MCM[/color] settings or [color=#ffd966]ModConfiguration.xml[/color] in mod folder, [color=#f6b26b]repeat the problem[/color], then attach the file from [color=#ffd966]Modules[/color]\[color=#f1c232]SkillMasteryRedux[/color]\[color=#ffd966]logs[/color] to your [url=https://www.nexusmods.com/mountandblade2bannerlord/mods/2018]ButterLib[/url] crash report.

[color=#ffff00][size=4]For Coders[/size][/color]
The minimum learning rate is a Harmony postfix on [color=#ffe599]DefaultCharacterDevelopmentModel[/color].[color=#b6d7a8]CalculateLearningRate[/color], not a replaced model.
The attribute bonuses are postfixes on the default models too; the wage bonus patches [color=#ffe599]DefaultPartyWageModel[/color].[color=#b6d7a8]GetTotalWage[/color] instead of replacing the wage model like Better Attributes did.
